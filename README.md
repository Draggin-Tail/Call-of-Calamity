# Call of Calamity

A tactics game for mobile browsers. Plain JavaScript, no build step.

- `game/` – the game. Open `game/index.html` in a browser (serve the folder over HTTP so the scripts and art load).
- `game/data/` – rules and data (`campaign.js` is the world map and campaign rules).

This repo is the source of truth for the code. Design notes still live in the claude.ai Project "Tactics Game" for now.
